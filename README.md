A 1024x1024 newspaper-style poster summing up Wednesday, 25 November 2026 in four stories: an Israeli airstrike in Gaza City kills Hamas internal security chief Naeem Abu Nahel, NATO pledges to defend space amid reports Russia is preparing a nuclear-armed satellite, Pakistan's first astronaut launches aboard China's Shenzhou-24 to the Tiangong space station, and AI stocks slump as Nvidia falls about 6% and the Nasdaq drops 1.5% after reports of a new US tariff plan. Drawn from scratch with Python + Pillow — every illustration is original, no photos or downloaded assets — and fully deterministic: two runs produce byte-identical output. The drawing code is in `draw_poster.py`; `main.py` (standard library only) copies the pre-rendered `entry.png` to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
